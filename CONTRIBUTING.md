# Contributing

Use a linked issue, a focused branch and a small pull request. Read AGENTS.md and the requirements first. Document the current behavior, change, positive and negative tests and privacy implications. Do not submit real personal information, credentials, private keys or sensitive production artifacts. Keep cryptographic formats compatible with the pinned reference implementation. An AI review is not an independent security audit.

By contributing, you license your original contributions under AGPL-3.0-only. Preserve third-party attribution. Follow CODE_OF_CONDUCT.md and report vulnerabilities privately under SECURITY.md.
